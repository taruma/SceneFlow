# SceneFlow v2.5.0: Studio Script Editor, Centralized Shortcuts & High-Performance Architecture

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: September 16, 2026* • *Tag: `v2.5.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

Following the monumental redesign of Edit Mode in **v2.4.0**, **SceneFlow v2.5.0** delivers a comprehensive evolution in screenplay authoring, keyboard navigation, state machine analysis, and runtime performance.

This release introduces the **Studio Script Editor**—a modular, 3-panel authoring environment with hierarchical document outlines, pixel-perfect soft word-wrapping, and an integrated formatting guide. It establishes a **Centralized Keyboard Shortcuts Registry** with an interactive cheat-sheet modal (<kbd>?</kbd>), debuts the **BRIEF State Engine** analysis deck in the Cue Inspector, and achieves massive performance milestones: **zero-lag instantaneous theme switching** and a **70% reduction in initial JavaScript bundle payload**.

## 🌟 What's New in v2.5.0

### 1. Studio Script Editor (`RawScriptModal` & `raw-script/`)

The monolithic screenplay modal has been completely overhauled into a professional, studio-grade 3-panel workspace (`max-w-7xl` / 1280px) designed for deep writing and complex multi-part scripts:

- **4-Rank Collapsible Hierarchical Outline**:
  - Automatically parses `PART`, Roman numeral acts (`I. ...`), scene headings (`INT./EXT.`), staging containers (`[[STAGING]]`), brief execution blocks (`[<BRIEF>]`), and directive tags.
  - Features per-section child count badges, individual chevron toggles, and unified **Collapse All / Expand All** controls.
  - Selecting an outline section automatically unfolds any collapsed ancestors and smooth-scrolls the caret directly to the target line.
- **Soft Word-Wrap with Pixel-Perfect Gutter Alignment**:
  - Toggleable via the toolbar `[ Wrap ]` button or <kbd>Alt+Z</kbd>.
  - Uses an off-screen measurement mirror container (`lineHeights`) with identical typography and padding to calculate exact rendered row heights, maintaining strict 1:1 pixel alignment between line numbers and wrapped text rows without vertical drift during deep scrolling.
- **Searchable Formatting Guide Sidebar**:
  - Built-in right-hand cheat sheet (`[ Guide ]` toggle) with live search and category filtering (`Structure`, `Directives`, `Dialogue`, `Effects`).
  - Provides 1-click **Insert** and **Copy** actions alongside live visual preview badges that mirror SceneFlow's screenplay rendering engine.
- **Streamlined Single-Tier Toolbar**:
  - Streamlined into a single 40px row (`h-10`, `flex-nowrap overflow-x-auto`) that permanently eliminates awkward two-tier button wrapping.
  - Hosts a segmented view switcher (`Outline`, `Wrap`, `Guide`), container wrapping shortcuts (`[[STAGING]]`, `[<BRIEF>]`), core directive presets (`INTENT`, `LOGIC`, `AESTHETIC`, `OPENING`), saved custom tags with removal pips, custom tag creator modal, and right-aligned history (Undo/Redo) and document utilities.
- **Debounced Undo/Redo Engine**:
  - Full keyboard (<kbd>Ctrl+Z</kbd>, <kbd>Ctrl+Y</kbd>, <kbd>Ctrl+Shift+Z</kbd>) and toolbar history engine with 300ms input debouncing, preserving exact caret indices and scroll positions across undo/redo operations.
- **Persistent Custom Directive Tags**:
  - Store user-defined directive tags in `localStorage` (`sceneflow_custom_script_tags`), with smart selection wrapping (`[[TAG]]...[[/TAG]]`) and seamless insertion at cursor.
- **Fast Keyboard Commit**:
  - Press <kbd>Ctrl+Enter</kbd> (or <kbd>Cmd+Enter</kbd>) directly from the editor canvas to apply changes without reaching for the mouse.

### 2. Centralized Keyboard Shortcuts & Interactive Cheat-Sheet

Keyboard interaction across SceneFlow is now powered by a centralized metadata registry (`src/constants/shortcuts.ts`) and a dedicated modal:

- **Interactive Cheat-Sheet Modal (`KeyboardShortcutsModal`)**:
  - Triggered globally from anywhere in the app via <kbd>?</kbd> (<kbd>Shift+/</kbd>), through Studio Preferences (`[ ⚙️ Settings ▾ ]`), or via the App Info dialog.
  - **Live Multi-Attribute Search**: Matches against label, description, key names, and aliases in real time.
  - **6 Category Tabs**: Playback & Media, Studio Preferences, Script Editor, Cue Inspector, Splitters & Layout, and General & Navigation.
  - **Platform-Aware Key Glyphs**: Automatically detects client OS, displaying macOS symbols (<kbd>⌘</kbd>, <kbd>⌥ Option</kbd>, <kbd>⇧ Shift</kbd>) or PC keys (<kbd>Ctrl</kbd>, <kbd>Alt</kbd>, <kbd>Shift</kbd>).
  - **Zero Layout Shift**: Locked `h-[620px]` container prevents vertical jumping when switching tabs.
- **New Quick Navigation Hotkeys**:
  - <kbd>Shift+F</kbd> / <kbd>Alt+F</kbd>: Toggle desktop File dropdown menu.
  - <kbd>Shift+S</kbd>: Directly open the Source Script Editor from anywhere.
  - <kbd>Shift+E</kbd>: Directly open the Sync Cues JSON editor from anywhere.
  - <kbd>Shift+L</kbd>: Directly open the Screenplay Library catalogue.

### 3. BRIEF State Engine Analysis Deck

For technical screenplays and Auteur Scripts featuring `[<BRIEF>]` state machine blocks:

- **State Engine Analysis Engine (`briefAnalysis.ts`)**:
  - Parses modular state transitions chained by `->` (e.g. `[S01] IDLE -> [S02] SCANNING -> [S03] LOCK`).
  - Aggregates overall **Macro-States ($S_n$)** and **Total Sub-States** metric counters.
  - Partitions multi-scene execution blocks using sequential `briefSectionIndex` stamps.
- **Contextual Scene Anchoring**:
  - Dynamically resolves the nearest preceding scene heading or Part separator to label each section clearly.
- **Idle Cue Inspector Overview Deck**:
  - When no cue is actively selected in Edit Mode, the Cue Inspector displays the **BRIEF State Engine** summary deck with macro/sub-state counts, section cards, and state ranges ($S_{start}–S_{end}$).
  - Automatically hidden on traditional screenplays without `[<BRIEF>]` tags to keep the workspace clean and focused.

### 4. High-Performance Architecture

v2.5.0 introduces architectural performance optimizations eliminating UI stutter and slashing download sizes:

- **Instant Theme Switching & Transition Suppression Engine**:
  - Eliminated sluggish `0.25s` and `200ms` CSS background/color transitions that previously triggered full-DOM repaint thrashing during theme changes.
  - Added `disableTransitionsTemporarily()`: momentarily injects `.disable-theme-transitions` (`transition: none !important;`) onto `document.documentElement` during theme, script paper, and pure black switches, flushes layout via `offsetHeight`, and removes the class via double-RAF. Theme switching is now instantaneous and lag-free.
  - Added global `@media (prefers-reduced-motion: reduce)` support in `src/index.css`.
- **70% Initial Bundle Footprint Reduction**:
  - Converted secondary modals (`RawScriptModal`, `RawCuesModal`, `LibraryModal`, `MobileLibraryModal`, `ScriptColorModal`, `MobileColorModal`, `KeyboardShortcutsModal`, `AppInfoModal`, `TimingSettingsModal`, `StagingModal`) to dynamic `React.lazy()` imports wrapped in `<Suspense fallback={null}>`.
  - Configured Rollup `manualChunks` in Vite to isolate vendor dependencies (`vendor-react`, `vendor-motion`, `vendor-icons`, `vendor-player`).
  - Slashing initial entry bundle from **778 kB down to 243 kB** (gzip: **215 kB down to 65 kB**), eliminating all Vite bundle warnings and isolating motion animation code strictly to modal launches.
- **Fast-Path Script Outline & CSS Virtualization**:
  - Character prefix pre-filtering (`[`, `#`, sections) skips 95% of regex evaluations on dialogue/action lines.
  - Replaced recursive tree walks with a single-pass bottom-up $O(N)$ graph accumulation.
  - Applied `content-visibility: auto` and `contain-intrinsic-size: 26px` to outline rows, enabling the browser to skip layout and painting for off-screen sections.

### 5. Universal Data Access & Critical Bug Fixes

- **Universal File Dropdown Access**:
  - `Sync Cues (JSON)...` and `Source Script...` are now surfaced directly in the desktop `[ File ▾ ]` dropdown menu across both Playback and Edit modes, removing mode-switching friction.
- **Restored Confirmation Dialogs & Overlap Picker**:
  - Re-mounted `ResetConfirmationModal`, `DeleteConfirmationModal`, and `OverlapPicker` in `App.tsx`, resolving an issue where library loading, cue deletion prompts, and shared-line overlap selection appeared unresponsive.
- **Auto-Scroll Upcoming Cue Fallback & Center-Tracking Spacers**:
  - Added `findScrollTargetCue` to keep the viewport centered on upcoming cues during silence gaps or pauses between dialogue lines.
  - Added dynamic top/bottom viewport spacers (`H/2`) to enable true vertical center-tracking for boundary cues at the extreme start and end of timelines.
- **Collapsible Filter Drawer Decoupling**:
  - Decoupled filter drawer expansion from active filter state in `SyncCuesToolbar`, allowing users to collapse the drawer to reclaim screen space while keeping filters active.

## 🔍 Detailed Changes & Invariants

### Architectural Highlights

1. **Script Editor Modularization (`src/components/raw-script/`)**:
   - Decoupled the monolithic 700+ line modal into a clean subpackage:
     - `types.ts`: Outline nodes, history snapshots, and directive presets.
     - `hooks/`: Isolated state machines (`useScriptHistory`, `useScriptOutline`, `useWordWrap`, `useCustomTags`).
     - `components/`: Memoized sub-components (`ScriptModalHeader`, `ScriptOutlineSidebar`, `ScriptEditorToolbar`, `ScriptEditorCanvas`, `ScriptFormattingGuide`, `ScriptEditorFooter`).
2. **Zero-Regression Dependency Pruning**:
   - Removed unused server dependencies (`express`, `@types/express`, `dotenv`), unused AI SDK (`@google/genai`), and duplicate packages. Knip audit confirmed 0 unused dependencies across the repository.
3. **Canonical Nomenclature**:
   - Unified UI copy to the canonical "Script" standard ("Script Editor", "Script" tab), replacing legacy "Screenplay" naming across shortcuts, tooltips, and headers.
