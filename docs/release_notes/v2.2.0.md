# SceneFlow v2.2.0: Dynamic Multi-Theming, Mobile Drawer, & Modal Ergonomics

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: August 29, 2026* • *Tag: `v2.2.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.2.0** introduces a dynamic multi-theme system (**Light**, **Warm**, and **Dark** modes), a dedicated **Mobile Theme Drawer** (`MobileColorModal`), an **Adaptive Dynamic Logo**, universal **Modal `Escape` Key & Backdrop Dismissal**, an in-app **Desktop About & Info Modal**, and comprehensive **Component Contrast Hardening** across all 18 components.

---

## 🌟 Highlights

- **🌓 Dynamic App Shell Theming (Light / Warm / Dark)**: Full-app dynamic color schemes with seamless CSS variable switching across `:root`, `[data-theme-category="warm"]`, and `[data-theme-category="dark"]`.
- **🔄 Auto-Synchronization with Screenplay Themes**: The application shell automatically adapts its theme category to coordinate with the active screenplay paper preset (*Studio Crisp* $\rightarrow$ Light, *Warm Parchment* $\rightarrow$ Warm, *Midnight Slate* $\rightarrow$ Dark).
- **⚡ Header Quick Theme Switcher**: Dedicated header button allowing one-click cycling through `Auto`, `Light`, `Warm`, and `Dark` modes with `localStorage` persistence.
- **📱 Dedicated Mobile Theme Drawer (`MobileColorModal.tsx`)**: Bottom-sheet drawer with 4-segment App Shell switcher and 6 compact screenplay paper swatches styled in their true paper colors and typography contrast.
- **🖼️ Adaptive Dynamic Logo**: Zero-JS-lag CSS selectors automatically display `/SCENEFLOW_TAG_B.png` in Light/Warm modes and `/SCENEFLOW_TAG_WHITE.png` in Dark mode.
- **⌨️ Universal Modal `Escape` Key & Backdrop Dismissal**: Reusable `useEscapeKey` hook unifying keyboard and click-to-dismiss behavior across all 8 application modals.
- **ℹ️ Desktop App Info & About Modal (`AppInfoModal.tsx`)**: In-app overview displaying dynamic metadata (`v2.2.0`), author attribution (**Taruma Sakti**), key capabilities, shortcut cheat sheet, and documentation links.
- **🎯 Precision Edit-Mode Highlighting**: DOM-anchored character offset calculation in `cueUtils.ts` ensuring accurate cue placement on repeated keywords and phrases.
- **🛡️ Contrast Hardening & Badge Centering**: Normalized all 18 components to semantic tokens; fixed badge contrast, modal header icon wrappers, and category count centering across desktop and mobile modals.

### 2. 📱 Streamlined Mobile Theme Drawer (`MobileColorModal.tsx`)

A native bottom-sheet drawer optimized for smaller viewports:

- **4-Segment App Shell Mode Switcher**: `[ ✨ Auto | ☀️ Light | ☕ Warm | 🌙 Dark ]` with dynamic status text.
- **6 Compact Screenplay Swatches**: Clean minimal cards styled directly with `theme.paperBg` and `theme.textColor`, omitting multi-line dummy script blocks for quick thumb-friendly scrolling.
- **Mobile Trigger**: `<Palette size={10} /> Theme` button placed in the mobile playback control bar alongside the Library button.

---

### 3. ⌨️ Universal Modal Ergonomics (`useEscapeKey.ts`)

Standardized keyboard and pointer dismissal across all 8 modal dialogs:
- `ScriptColorModal` (Desktop Themes)
- `MobileColorModal` (Mobile Drawer)
- `LibraryModal` (Desktop Catalogue)
- `MobileLibraryModal` (Mobile Catalogue Drawer)
- `TimingSettingsModal` (Timing Buffers)
- `AppInfoModal` (About & Shortcuts)
- `RawScriptModal` & `RawCuesModal` (Raw Editors)
- `DeleteConfirmationModal` & `ResetConfirmationModal` (Confirmation Dialogs)

---

### 4. 🛡️ Component Contrast Hardening & Fixes

- **Library Modal Featured Cards**: Replaced hardcoded brown light-mode utilities (`text-amber-950`, `text-amber-800`, `bg-amber-100`) with high-contrast semantic typography (`text-text-main group-hover:text-amber-500`) and glowing amber borders (`border-amber-500/30`).
- **Category Badge Centering**: Added `inline-flex items-center justify-center min-w-[18px] h-4 leading-none` to guarantee mathematical vertical and horizontal number centering across desktop and mobile modals.
- **Modal Header Icons**: Updated `UI_TOKENS.iconWrapper.dark` to use `bg-btn-primary-bg text-btn-primary-text`, dynamically inverting to high-contrast white badges in Dark mode.
- **Adaptive Logo**: Added CSS rules `.logo-light` and `.logo-dark` to display dark logo on Light/Warm surfaces and white logo on Dark surfaces.
