# SceneFlow v2.0.0

> **Screenplay-to-video synchronization for AI filmmakers.**  
> *Release Date: August 26, 2026* • *Tag: `v2.0.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.0.0** is our most significant release to date. This milestone transforms SceneFlow from a monolithic prototype into a modular, high-performance, and visually customizable web application for analyzing screenplay-to-screen fidelity in AI filmmaking.

This major release introduces a brand new **Script Theme Engine** with six visual presets, configurable **Screenplay Width and Auto-Scroll Focus Presets**, an **In-Place Cue Text Editor**, a dedicated **Mobile Library Experience**, an expanded **Cinematic Example Catalogue**, and a complete **Architectural Modernization** powered by a suite of eight custom React hooks and centralized design tokens.

---

## 🌟 Highlights

- **🎨 Script Theme Engine**: Switch between 6 curated visual themes (*Studio Crisp*, *Warm Parchment*, *Retro Newspaper*, *Midnight Slate*, *OLED Black*, and *Cyber Matrix*) with theme-calibrated cue highlight spectrums and live preview inspection.
- **🧩 Modular 5-Layer Architecture**: Deconstructed the monolithic `App.tsx` into a clean, testable architecture powered by 8 custom hooks, 18 isolated sub-components, and pure cue processing utilities.
- **📐 Viewport & Focus Customization**: Customize your reading flow with 5 column width presets (Narrow to Expanded) and 3 auto-scroll anchor positions (Top 35%, Center 50%, Bottom 35%).
- **✏️ In-Place Cue Editing**: Edit cue text directly inside the cue panel without editing raw JSON, backed by multi-tier fuzzy matching and alternative occurrence finders.
- **📱 Polished Mobile & PWA Experience**: Purpose-built mobile library modal, responsive staging badges, branded initialization screen, and full PWA asset suite.
- **📚 Expanded Example Library**: 7 new cinematic examples added to the catalogue—including the new default *Scene Frequency* guide script, *Wonder*, *What We Leave*, and *A Duet of Distance*.
- **⚡ Modernized Technology Stack**: Built on React 19, TypeScript 5.8, Tailwind CSS v4, Motion, Vite 6, and integrated with `@vercel/analytics`.

## 🔍 Key Features

### 1. 🎨 Script Theme System & Design Tokens

SceneFlow now features a comprehensive styling engine designed to optimize contrast, readability, and aesthetic comfort across diverse screen environments:

| Theme | Type | Style Summary | Ideal Use Case |
|---|---|---|---|
| **Studio Crisp** | Light | Clean white paper with modern slate typography *(Default)* | Daytime reading & precision review |
| **Warm Parchment** | Warm | Classic amber/sepia paper with rich espresso text | Long-form reading & classic screenplay feel |
| **Retro Newspaper** | Warm | High-contrast newsprint paper with ink-black monospace text | High-contrast review & print proofing |
| **Midnight Slate** | Dark | Refined deep slate paper with luminous cool-grey text | Low-light studio environments |
| **OLED Black** | Dark | Pure `#000000` pitch background with sharp white text | OLED/AMOLED displays & battery saving |
| **Cyber Matrix** | Dark | Terminal dark paper with vivid neon-green accents | Stylized AI prompt inspection |

- **Theme-Calibrated Cue Highlights**: All eight cue categories (Dialogue, Action, Camera, Shot, Audio, VFX, Transition, Environment) dynamically adjust their RGB transparency and border hues based on the active theme for optimal legibility.
- **Centralized Design Token Package (`src/styles/`)**: Centralized `UI_TOKENS` for modals, dialogs, form controls, action pills, buttons, and alert cards, ensuring visual consistency across all components.
- **Live Preview Modal**: The `ScriptColorModal` includes an interactive inspector previewing theme surface textures, borders, punch holes, and the full 8-color cue spectrum in real time.
- **Persistence**: Theme selections automatically persist to `localStorage` (`sceneflow_script_theme`).

### 2. 🧩 Modular Architecture & Custom Hooks Suite

The codebase has undergone a full architectural refactoring, separating concerns into a 5-layer modular system:

1. **Processing Layer** (`src/lib/scriptParser.ts`, `src/lib/scriptProcessor.ts`): Script line classification and staging block extraction.
2. **Utility Layer** (`src/lib/cueUtils.ts`, `src/lib/utils.ts`, `src/constants/script.ts`): 9 pure cue functions, constants, and ID sanitization.
3. **Visuals & Design Tokens Layer** (`src/styles/`): Reusable UI tokens, color maps, theme definitions, and typography helpers.
4. **State & Hooks Layer** (`src/hooks/`): 8 custom React hooks managing player, storage, preferences, and editor state.
5. **Presentation Layer** (`src/App.tsx`, `src/components/`): Lightweight orchestrator with 18 focused sub-components.

#### Custom Hooks Suite
- `useScriptStorage` (`src/hooks/useScriptStorage.ts`): Handles state initialization, `localStorage` caching, blank starter loading, example switching, and CORS-aware remote project fetching (`?project=URL`).
- `useYouTubePlayer` (`src/hooks/useYouTubePlayer.ts`): Manages YouTube IFrame Player binding, playback synchronization, high-frequency 100ms time tracking, and transport controls.
- `useScriptPreferences` (`src/hooks/useScriptPreferences.ts`): Manages theme selection, reading width presets, scroll focus anchors, and cue category filtering with `localStorage` persistence.
- `useAutoScroll` (`src/hooks/useAutoScroll.ts`): Real-time screenplay auto-scrolling with multi-target filtering and ratio-based viewport alignment.
- `useCueEditor` (`src/hooks/useCueEditor.ts`): Cue authoring, selection ranges, in-place text modification, and timeline seeking.
- `useCueAlignment` (`src/hooks/useCueAlignment.ts`): Automated and manual cue realignment against modified script text.
- `useKeyboardShortcuts` (`src/hooks/useKeyboardShortcuts.ts`): Hotkeys (`Space`, `ArrowLeft`, `ArrowRight`) with form input gating and modal bypass.
- `useScriptTheme` (`src/hooks/useScriptTheme.ts`): Dynamic theme resolution, computed theme class bundles, dynamic cue RGB resolution, and dark mode detection.

### 3. 📐 Viewport Customization: Width & Scroll Focus Presets

Tailor the reading layout to your screen size, workflow, and reading habits:

- **Five Column Width Presets**:
  - `Narrow` (384px)
  - `Compact` (448px)
  - `Standard` (576px, default)
  - `Wide` (768px)
  - `Expanded` (1024px)
- **Three Scroll Focus Anchors**:
  - `Top (35%)`: Positions active line near the top, prioritizing anticipation of upcoming script dialogue and action.
  - `Center (50%)`: Balanced midpoint alignment.
  - `Bottom (35%)`: Positions active line near the bottom, prioritizing context of recently passed lines.

---

### 4. ✏️ In-Place Cue Editing & Alignment Engine

- **Direct Monospace Editor**: Edit cue text directly inside the *Edit Sync Cue* panel without touching raw JSON data.
- **Robust Text Finder (`findTextInScript`)**: Three-tier lookup system (exact match → normalized whitespace & smart quotes regex → case-insensitive search).
- **Find Alternative Locations**: Proximity-aware regex finder identifies duplicate occurrences across the script with 25-character context snippets while safely ignoring hidden `[[STAGING]]` metadata blocks.
- **Deterministic Cue Sanitization (`sanitizeCues`)**: Standardized data sanitization pipeline executing across all 5 data ingress points to eliminate duplicate IDs and infer cue types and colors bidirectionally.

- **Script Theme Engine**: 6 visual presets (`Studio Crisp`, `Warm Parchment`, `Retro Newspaper`, `Midnight Slate`, `OLED Black`, `Cyber Matrix`) with live modal inspector and `localStorage` persistence.

- **Custom React Hooks Suite**: 8 modular hooks in `src/hooks/` consolidating state, player transport, preferences, auto-scroll, cue editing, alignment, shortcuts, and themes.
- **Reading Width Presets**: 5 configurable desktop reading-column widths (`Narrow`, `Compact`, `Standard`, `Wide`, `Expanded`).
- **Scroll Focus Presets**: 3 configurable auto-scroll anchor positions (`Top 35%`, `Center 50%`, `Bottom 35%`).
- **In-Place Cue Text Editing**: Direct monospace text editor in the Edit Cue form.
- **Dedicated Pure Utilities Module (`src/lib/cueUtils.ts`)**: 9 pure functions for sanitization, alignment, multi-tier search, opacity calculation, and JSON validation.
- **Mobile-Specific Library Modal (`MobileLibraryModal`)**: Touch-optimized browsing drawer for handheld viewports.
- **Branded Initialization Splash Screen**: Fast first-load screen featuring the SceneFlow logo and pulse animation.
- **PWA & Favicon Assets**: Complete icon suite (`apple-touch-icon`, Android Chrome 192/512px, favicon ICO/PNG) and `site.webmanifest`.
- **Custom Dark Scrollbar Utility**: `.custom-dark-scrollbar` utility for unified modal scroll styling.
- **7 New Screenplay Examples**: Added *Scene Frequency*, *Museum*, *Still Here*, *The Magic Card*, *Wonder (Vol 6)*, *What We Leave (Vol 7)*, and *A Duet of Distance*.
- **Dynamic Library Badges**: Contextual section tags on cards with matching icons.
- **Vercel Analytics**: Audience traffic insights integration.
- **Ko-fi Donation Link**: Support button in mobile navigation.

### 🔄 Changed
- **Architectural Refactoring**: Decomposed monolithic `App.tsx` into 18 isolated sub-components and 8 custom hooks.
- **Dynamic Cue Color Resolution**: Replaced static Tailwind color classes with dynamic theme-calibrated RGB inline styling derived from cue `type`.
- **Sanitization Pipeline**: Standardized all project loading paths through `sanitizeCues()` for deterministic key generation and type normalization.
- **Brief Block Enhancements**: Added waterfall indentation for `->` sequences, suppressed empty whitespace lines, and applied theme-aware card borders.
- **Staging Mobile Layout**: Adapted staging badge sizing and margins for mobile screens with `flex-wrap` protection.
- **Directory Restructuring**: Organized example JSON files into `public/examples/` and `public/examples/ai_clips/`.
- **Default Guide Script**: Set *Scene Frequency* as the default script on first launch.
- **Documentation Refresh**: Complete overhaul of `docs/ARCHITECTURE.md`, `docs/FUNCTIONALITY.md`, `docs/TECH_STACK.md`, `docs/AGENTS.md`, and `README.md`.

### 🗑️ Removed
- **Obsolete AST Block Parser**: Removed unused `parseScriptToBlocks()` and `ScriptBlock` types.
- **Legacy Static Theme Fallbacks**: Removed static `SCRIPT_STYLES` in favor of dynamic theme resolution.
- **Dead Code & Props**: Cleaned up unused props, dead variables, and debug console logs across components.

### 🐛 Fixed
- **Mobile Script Width Selector**: Hid desktop-only width dropdown on mobile viewports to prevent layout crowding.
- **Brief Block Empty Card Bug**: Filtered out whitespace-only lines to eliminate ghost empty cards.
- **Waterfall Formatting Artifacts**: Resolved edge-case double newlines and blank leading lines in formatted brief segments.
- **Staging Tag Parser**: Trimmed whitespace during inner staging label matching (`[[LABEL]]...[[/LABEL]]`).

## 💾 Migration & Compatibility Notes

- **Backwards-Compatible JSON Schemas**: Existing project JSON files and exports from v1.x remain 100% compatible with v2.0.0. Missing `colorClass` or IDs are automatically normalized on import.
- **LocalStorage Keys**: User preferences are saved under dedicated keys:
  - `sceneflow_script_theme` — active script theme ID
  - `sceneflow_script_width_preset` — reading column width preset
  - `sceneflow_scroll_focus_preset` — auto-scroll anchor preset
  - `screenplay_sync_state` — active screenplay text and cues
