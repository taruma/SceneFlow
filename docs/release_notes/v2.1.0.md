# SceneFlow v2.1.0: Interactive Onboarding Guide & Design Token Harmonization

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: August 28, 2026* • *Tag: `v2.1.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.1.0** focuses on in-app user onboarding, design system harmonization, and catalogue expansion. This release delivers a completely re-engineered **Interactive Onboarding Starter Guide (`blank.json`)**, a unified **UI Design Token System** (`UI_TOKENS` & CSS variable palettes) across all app chrome components, **new curated AI clip examples**, and comprehensive **Documentation & Specification Synchronization** across the repository.

---

## 🌟 Highlights

- **🎓 Interactive Onboarding Starter Guide**: Rebuilt the default guide (`public/examples/blank.json`) into an interactive, self-demonstrating tutorial loaded directly in playback mode via the header **Guide** button.
- **🎨 UI Design Token Harmonization**: Consolidated all outer application chrome styling into standard `UI_TOKENS` across 9 functional categories in `src/styles/tokens/ui.ts`.
- **🌈 Semantic CSS Palette Variables**: Defined 18 `:root` CSS custom properties in `src/index.css` mapped directly into Tailwind CSS v4's `@theme` directive.
- **🧩 Shell Component Token Refactoring**: Refactored application chrome and modal components (`AppHeader`, `ScriptHeaderControls`, `LibraryModal`, `StagingModal`, `ActiveHighlightsPanel`, `TimelineCuesPanel`, `CueEditorForm`, `TimingSettingsModal`) to consistently consume centralized tokens without visual regressions.
- **🎬 New AI Clip Catalogue Additions**: Expanded the built-in Library Catalogue with new short-form prompt execution vignettes (see [SceneFlow Catalogue](../../SCENEFLOW_CATALOGUE.md)).
- **📖 Documentation & Heuristics Synchronization**: Updated `README.md`, `docs/FUNCTIONALITY.md`, `docs/ARCHITECTURE.md`, `docs/AGENTS.md`, and `SCENEFLOW_CATALOGUE.md` to reflect deterministic parsing heuristics, UI design tokens, and modular staging architecture.

### 2. 🎨 UI Design System Harmonization & CSS Custom Properties

To eliminate ad-hoc classes, ensure visual consistency, and decouple the Screenplay Paper Canvas from outer application chrome, v2.1.0 unifies all application chrome styling:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        DESIGN TOKEN SEPARATION                         │
├──────────────────────────────────┬─────────────────────────────────────┤
│     SCREENPLAY PAPER CANVAS      │           APP SHELL CHROME          │
│  src/styles/tokens/themes.ts     │  src/styles/tokens/ui.ts            │
│  src/styles/tokens/cues.ts       │  src/index.css (:root custom props) │
│  src/styles/tokens/typography.ts │  Tailwind CSS v4 @theme mapping     │
└──────────────────────────────────┴─────────────────────────────────────┘
```

#### Centralized `UI_TOKENS` (`src/styles/tokens/ui.ts`):
Consolidates reusable Tailwind class bundles across 9 functional categories:
1. **`layout`**: App header, script headers (playback & edit modes), panel frames (`leftPanelBase`, `rightPanelBase`), and section titles (`sectionTitle`, `sectionTitleMini`).
2. **`modal`**: Overlays (`overlay`, `overlayHeavy`, `overlayHighZ`), responsive containers (`containerSm`, `containerMd`, `containerLg`, `containerXl`, `containerLibrary`, `containerStaging`), standard headers, footers, and padding tokens (`dialogPad`, `bodyPad`).
3. **`dropdown`**: Focus mode, script width, and scroll focus dropdown menus (`menu`, `menuWide`), headers, titles, items, and active item highlights.
4. **`button`**: Primary, secondary, danger, header icon action buttons (`headerIconButton`, `headerIconButtonActive`), mode switchers (`modeSwitchContainer`, `modeSwitchActive`, `modeSwitchInactive`), sort toggles, action pills, support pills, and close buttons.
5. **`input`**: Search inputs, multiline textareas, code textareas, number boxes, and label typography.
6. **`panel`**: Data banners, interactive cards (`card`, `cardInteractive`, `cardInteractiveActive`), empty placeholders, and legend containers.
7. **`badge`**: Counter tags (`counter`, `counterFaint`), timestamp pills (`timeTag`), and header current time badges (`currentTimePill`).
8. **`swatch` & `alert`**: Theme preview swatches and notification banners.

#### Semantic CSS Variables (`src/index.css`):
18 CSS custom properties defined in `:root` and mapped directly into Tailwind CSS v4's `@theme` directive:
- **Surfaces**: `--app-bg`, `--surface`, `--surface-subtle`, `--surface-muted`, `--surface-hover`, `--surface-dark`
- **Borders**: `--border-main`, `--border-subtle`, `--border-subtle-trans`
- **Text**: `--text-main`, `--text-body`, `--text-muted`, `--text-faint`, `--text-placeholder`
- **Overlays & Accents**: `--overlay-bg`, `--overlay-heavy`, `--color-support`, `--color-support-hover`
