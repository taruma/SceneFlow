# SceneFlow v2.3.0: Multi-Track Sync Timeline, Decoupled Split Panes, Collapsible Player, & 360° Palette Overhaul

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: September 10, 2026* • *Tag: `v2.3.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.3.0** is a major milestone release transforming the playback and inspection experience into an NLE/DAW-grade workflow. This release introduces a horizontal **Multi-Track Sync Timeline** with stationary playhead anticipation, a docked **Paused Cue Inspector**, **Dual-Axis Draggable Split Panes** with a 1-click **Reset View**, a **Collapsible Video Player** with zero-height background audio continuity, persistent **Header Transport Controls**, an **Adaptive Highlights Toolbar**, an opt-in **Cue Palette Accessibility Profile (Protanopia/Deuteranopia Safe Mode)**, an overhauled **360° Harmonized Cue Palette**, and a dedicated **Pure Black Canvas (Video Overlay Mode)** tailored for video compositing and timeline screen recording.

---

## 🌟 Highlights

- **📊 Multi-Track Sync Timeline (`src/components/active-highlights/`)**: Complete re-architecture of the playback Active Highlights panel from vertical cards into an NLE/DAW-inspired horizontal multi-track sync timeline featuring persistent category lanes, glowing playhead laser, and sliding real-time timecode ruler.
- **🎯 Stationary Anticipation Playhead & Continuous Timecode Ruler**: Fixed playhead at 35% from the left edge provides visual anticipation for upcoming cues, while continuous 1s ticks and MM:SS markers smoothly glide beneath the playhead.
- **🛡️ Deterministic Global Sub-Lane Stacking**: Interval-scheduled sub-lane assignment pre-calculates cue stacking across the entire script, completely eliminating vertical row-jumping or card juggling during scrubbing and playback.
- **🔍 Docked Paused Cue Inspector Card**: Automatically surfaces when playback is paused or a cue block is clicked, providing multi-cue tab switching, category-themed badges, serif italic screenplay quotes, precision timestamps (`MM:SS.s`), and a 1-click **Replay** button.
- **🔍 Timeline Zoom Presets (4s, 8s, 16s) & Flexible vs. Fixed Track Heights**: Context-aware toolbar options allowing creators to toggle between close-up dialogue inspection and macro scene overview, and switch between dynamic expansion and pre-allocated zero-layout-shift track heights.
- **🎛️ Studio VU Meter (8-Slot Category LED Strip)**: Hardware-inspired category LED meter anchored beside the active cue counter, illuminating dynamically with zero horizontal jitter during playback.
- **↔️ Dual-Axis Draggable Split Panes & Calibrated Default Layout**: Interactive pointer-captured split dividers for both horizontal column ratio (calibrated default 65:35, clamped 30%–72%) and vertical video monitor height (calibrated default 220px, 16:9 proportional scaling) with hardware VSync throttling and a 1-click header **Reset View** action.
- **🎬 Collapsible Video Player & Zero-Height Audio Continuity**: Ability to hide the YouTube video frame (<kbd>V</kbd> shortcut or header toggle) with zero-height CSS clipping, maintaining uninterrupted audio, playhead clock advancement, and auto-scroll for clean timeline screen recording.
- **⏯️ Persistent Header Transport Controls**: Dedicated `Play`, `Pause`, and `Replay 0:00` controls permanently mounted in the playback header, operable even when the video player is hidden.
- **♿ Opt-In Protanopia / Deuteranopia Accessibility Profile**: Solves Red-Green Color Vision Deficiency where Indigo (Shot) and Blue (Action) collapse into identical hues, remapping Shot to Deep Wine / Burgundy ($L^* \approx 25$ vs Action $L^* \approx 50$) paired with high-luminance Ice Aqua VFX ($L^* \approx 85$) and Vermilion Coral Transition.
- **🎨 360° Harmonized Standard Cue Palette Overhaul**: Balanced all 8 cue categories evenly across the 360° color wheel, eliminating pastel crowding (Transition: Crimson Rose, Shot: Deep Iris, VFX: Electric Aqua, Action: Royal Cobalt Blue, Camera: Emerald Green) with seamless backward compatibility normalization (`LEGACY_CLASS_MAP`).
- **⬛ Pure Black Canvas / Video Overlay Mode**: Dedicated workspace mode forcing absolute `#000000` luminance across canvas and timeline lanes, stripping drop shadows while preserving 1px borders for NLE screen recording and Screen/Lighten blend compositing.
- **🌓 Dark Mode Surface & Text Contrast Hardening**: Fixed current time counter digits and pill styling in dark and pure black themes (`text-white`), and added pre-emptive seek locks preventing YouTube unbuffered auto-play quirks.

## 🔍 Key Changes in v2.3.0

### 1. 📊 Multi-Track Sync Timeline (`src/components/active-highlights/`)

The playback Active Highlights panel has been transformed into a professional horizontal multi-track sync timeline:

```
┌────────────────────────────────────────────────────────────────────────┐
│                      MULTI-TRACK SYNC TIMELINE                         │
├────────────────────────────────────────────────────────────────────────┤
│ [Highlights] [Active: 3 ●●●○○○○○]     [Flex|Fixed] [4s|8s|16s] [Cards] │
├───────────┬───────────────────────────────┬────────────────────────────┤
│ CATEGORY  │ TIMECODE RULER: 01:14  01:15  │ 01:16  01:17  01:18        │
├───────────┼───────────────────────────────┼────────────────────────────┤
│ DIALOGUE  │          [ CUE BLOCK A ]      │       [ CUE BLOCK B ]      │
│ ACTION    │    [ CUE BLOCK C ]            │                            │
│ CAMERA    │                               │     [ CUE BLOCK D ]        │
│ SHOT      │ [ CUE BLOCK E ]               │                            │
│ AUDIO     │                               │            [ CUE BLOCK F ] │
├───────────┴───────────────────────────────┴────────────────────────────┤
│                 ▲ STATIONARY PLAYHEAD (35% LASER)                      │
├────────────────────────────────────────────────────────────────────────┤
│ DOCKED PAUSED INSPECTOR: [1 of 2] "Dialogue Quote..." 01:15.2 [Replay] │
└────────────────────────────────────────────────────────────────────────┘
```

- **Stationary Anticipation Playhead**: Anchored at 35% from the left edge of the timeline with a glowing laser line and pip, ensuring creators always have forward visibility of incoming cues.
- **Continuous Timecode Ruler (`TimelinePlayheadRuler.tsx`)**: Real-time sliding ruler with 1-second ticks and MM:SS markers synchronized with video playback.
- **Deterministic Sub-Lane Stacking (`useTimelineWindow.ts`)**: Greedy interval scheduling pre-allocates cue sub-lanes across the entire script duration, preventing overlapping blocks from jumping rows when entering the view window.
- **Dual-Time Buffer Activation**: Integrates lead-in and hold timing buffers into cue block and indicator dot illumination (`isCueActive()`), highlighting cues in lockstep with the script while preserving true media time boundaries on the ruler.
- **Docked Paused Cue Inspector (`PausedInspectorCard.tsx`)**: When playback is paused or a cue block is clicked, a docked card provides tabbed multi-cue navigation, category badges, quotes, timestamps, and an instant replay button.
- **Timeline Zoom Presets (`4s`, `8s`, `16s`)**: Discrete zoom presets adapt tick frequencies (1s labels for 4s, 2s labels for 8s, 2s ticks / 4s labels for 16s) with automatic text hiding and centered dots for narrow cue blocks.
- **Fixed vs. Flexible Track Height Modes**: Flexible mode expands tracks dynamically based on visible cues; Fixed mode pre-calculates the maximum script-wide sub-lanes (`globalMaxSubLane + 1`) to provide permanent track heights and dividers from 00:00.
- **High-Craft Modular Sub-Package**: Decomposed into `src/components/active-highlights/` with barrel export (`index.ts`), clean contracts (`types.ts`), calculation hook (`useTimelineWindow.ts`), and isolated track primitives (`TimelineLane.tsx`, `TimelineCueBlock.tsx`, `TimelinePlayheadRuler.tsx`, `PausedInspectorCard.tsx`).

### 2. 🎛️ Persistent Transport Controls & Studio VU Meter

```
┌────────────────────────────────────────────────────────────────────────┐
│                  PLAYBACK HEADER & STUDIO VU METER                     │
├────────────────────────────────────────────────────────────────────────┤
│ PLAYBACK   [ ▶ Play / ❚❚ Pause ]  [ ↺ Replay ]    [ ✕ Hide Video (V) ] │
├────────────────────────────────────────────────────────────────────────┤
│ HIGHLIGHTS [ Active: 2 ] [ ● Dialogue ● Action ○ Camera ○ Shot ... ]   │
└────────────────────────────────────────────────────────────────────────┘
```

- **Persistent Header Transport Controls (`PlaybackLeftPanel.tsx`)**: Added dedicated `Play` / `Pause` and `Replay 0:00` transport buttons in the left panel header, remaining fully mounted and operable even when the video player is hidden.
- **Studio VU Meter (8-Slot Category LED Strip)**: Fixed-slot category LED strip (`Dialogue`, `Action`, `Camera`, `Shot`, `Audio`, `VFX`, `Transition`, `Environment`) adjacent to the active counter, illuminating dynamically with zero layout shift.
- **Jitter-Free Numerical Isolation**: Isolated counter digit rendering (`min-w-[14px] font-mono tabular-nums`) preventing horizontal width jumping when counts oscillate.
- **Collapsible Filter Drawer**: Category pill filter bar collapses smoothly to save 35–40px of vertical space, featuring a pulsing dot indicator when categories are actively muted.
- **Adaptive Header Responsiveness**: `ResizeObserver` layout dynamically switches between a sleek single unified row (width $\ge 560\text{px}$) and a Two-Tier Header (width $< 560\text{px}$), preventing button squishing when adjusting split widths.

### 3. 🎬 Collapsible Video Player with Background Audio Continuity

- **Zero-Height Audio Continuity**: Toggle video visibility via header button or global <kbd>V</kbd> hotkey. Applies zero-height CSS clipping (`h-0 min-h-0 max-h-0 opacity-0 pointer-events-none overflow-hidden`) keeping the `<YouTube>` player iframe mounted in the DOM.
- **Uninterrupted Playback Engine**: Audio playback, playhead timecode progression, auto-scroll synchronization, and cue illumination continue smoothly without interruption.
- **Timeline Screen Recording**: Maximizes vertical screen height for the multi-track timeline, allowing clean, high-resolution screen recordings of timeline playback without video monitor clutter.
- **State Persistence & Reset**: Collapsed state is persisted in `localStorage` (`sceneflow_playback_video_collapsed`) and restored to default visibility on **Reset View**.

---

### 4. ↔️ Dual-Axis Draggable Split Panes & Calibrated Layout

- **Asymmetric Split Pane (`SplitPaneDivider.tsx`)**: Replaced rigid 50/50 desktop split with an interactive draggable divider. Defaults to a calibrated **65% Left (Playback & Timeline) / 35% Right (Script)** ratio (clamped between 30% and 72%), optimized for horizontal timeline width.
- **Absolute Minimum Width Constraint**: Added `MIN_PANEL_PIXEL_WIDTH = 380px` ensuring the left column never collapses into an unusable sliver on smaller desktop screens.
- **Vertical Video Height Split Divider (`VideoSplitDivider.tsx`)**: Interactive horizontal handle between video player and timeline supporting proportional 16:9 height resizing (calibrated default **220px**, clamped 160px–480px).
- **1-Click Header "Reset View"**: Added a dedicated `RotateCcw` button to the header toolbar, restoring default 65:35 split, 220px video height, and video visibility in a single click.
- **Hardware VSync Performance**: Resizing uses direct pointer capture, transparent iframe drag guards, and `requestAnimationFrame` throttling for smooth 60–144fps responsiveness, writing to `localStorage` only upon drag release.

### 5. ♿ Protanopia Accessibility Profile & 360° Palette Overhaul

SceneFlow v2.3.0 brings major visual science improvements to screenplay cue highlighting:

| Cue Category | Standard Palette (360° Overhaul) | Protanopia Profile (CVD Safe) | Accessibility Rationale |
| :--- | :--- | :--- | :--- |
| **Dialogue** | Sunlight Amber (`bg-amber-400/50`) | Sunlight Amber (`bg-amber-400/50`) | Universal warm clarity for dialogue lines |
| **Action** | Royal Cobalt Blue (`bg-blue-500/50`) | Royal Cobalt Blue (`bg-blue-600/50`) | High-saturation blue baseline ($L^* \approx 50$) |
| **Camera** | Emerald Green (`bg-green-500/50`) | Mint Emerald (`bg-emerald-500/50`) | Crisp cool green separating camera directions |
| **Shot** | Deep Iris / Indigo (`bg-indigo-400/50`) | **Deep Wine / Burgundy** (`bg-rose-900/60`) | **Eliminates Blue-Indigo ambiguity** in CVD; shifts hue to chocolate-wine ($L^* \approx 25$) with massive luminance separation |
| **Audio** | Vivid Tangerine (`bg-orange-400/50`) | Vivid Tangerine (`bg-orange-500/50`) | Distinct warm audio cue marker |
| **VFX** | Electric Aqua (`bg-cyan-400/50`) | **Radiant Ice Aqua** (`bg-cyan-300/60`) | Elevated luminance ($L^* \approx 85$) preventing green overlap |
| **Transition** | Crimson Rose (`bg-rose-500/50`) | **Vermilion Coral** (`bg-orange-600/60`) | Editorial cut mark distinct from wine and amber |
| **Environment** | Balanced Slate (`bg-slate-400/50`) | Balanced Slate (`bg-slate-400/50`) | Neutral backdrop framing scene settings |

- **Protanopia / Color Vision Deficiency Profile**: Solves Red-Green CVD confusion where Indigo and Blue collapse into identical hues due to reduced L/M cone sensitivity. Remapping Shot to Deep Wine/Burgundy provides deep luminance contrast ($L^* \approx 25$ vs $50$), instantly distinguishable.
- **Opt-In Profile Selector**: Easily toggle between `Standard` and `Protanopia` profiles inside `ScriptColorModal` and `MobileColorModal`, persisted in `localStorage` (`sceneflow_cue_palette_profile`).
- **Backward Compatibility Engine (`LEGACY_CLASS_MAP`)**: Automatically translates legacy cue color classes from older projects (`bg-purple-400`, `bg-pink-400`, `bg-cyan-400`) to canonical classes upon editing.

### 6. ⬛ Pure Black Canvas / Video Overlay Mode

- **Absolute `#000000` Luminance**: Opt-in mode in `ScriptColorModal` and `MobileColorModal` forcing true black across canvas, surfaces, and timeline lanes when dark script themes are active.
- **NLE Video Compositing**: Eliminates milky grey boxes or hazy wash when compositing screen recordings into video editors using **Screen** or **Lighten** blend modes.
- **Drop Shadow Stripping**: Automatically removes fuzzy drop shadow halos (`!shadow-none`) while cleanly preserving 1px borders (`activeTheme.paperBorder`) for sharp manuscript framing.
- **Two-Tier Decoupling**: Script Paper pure black rendering is completely decoupled from App Shell theme mode, preventing visual cross-layer leakage.

---

### 7. 🛡️ Seek State Integrity & Contrast Hardening

- **Auto-Play Suppression on Seek**: Pre-emptive seek locks suppress YouTube's unbuffered auto-play quirk (`BUFFERING (3) -> PLAYING (1)`) when clicking cues while paused.
- **Auto-Expiring Seek Guard**: 600ms auto-expiring seek lock prevents the "ghost pause" bug, ensuring clicks on the YouTube iframe immediately trigger playback.
- **Dark Mode Header Contrast**: Decoupled `UI_TOKENS.badge.currentTimePill` and counter digits from inverted button tokens to explicit `text-white`, eliminating unreadable ~1.1:1 contrast on dark surfaces.

## 📦 Migration & Compatibility

- **100% Backward Compatible**: Existing `.json` project files, sync cues, and local storage states load seamlessly.
- **Automatic Cue Migration**: Legacy cue color classes are automatically mapped to modern equivalents on edit via `LEGACY_CLASS_MAP`.
- **Zero Breaking State Changes**: All new settings (`splitRatio`, `videoHeight`, `timelineZoomPreset`, `timelineHeightMode`, `pureBlackBg`, `cuePaletteProfile`, `highlightViewMode`) include fallback defaults and do not alter existing project files.
- **Tailwind CSS v4 & TypeScript**: Fully verified and compiled with zero TypeScript diagnostics (`tsc --noEmit`) and clean Vite production bundling.
