# SceneFlow v2.4.0: Redesigned Edit Mode & Cue Management

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: September 15, 2026* • *Tag: `v2.4.0`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.4.0** is focused entirely on overhauling **Edit Mode**. Previously, editing cues relied on basic forms or modal overlays, and switching between Playback Mode and Edit Mode reloaded the YouTube video player—resetting playback progress back to `0:00` and stopping audio.

With v2.4.0, Edit Mode has been completely redesigned into a dedicated **3-panel desktop layout**, featuring a persistent video player that stays alive across mode switches, an overhauled **Cue Inspector** with timing steppers and dynamic loop preview, time-clustered cue cards with **Cards and Compact view modes**, collapsible filters and source controls, and a new **Cues JSON Editor** with ready-to-copy prompts and schemas for generating cues with Gemini.

---

## 🌟 What's New in Edit Mode

- **3-Panel Desktop Layout**: Desktop Edit Mode now organizes your workspace into three distinct panels:
  - **Left Panel (40%)**: Media player preview, transport controls, and chronological cue list.
  - **Center Panel (35%)**: Screenplay reading canvas with line-level highlighting.
  - **Right Panel (25%)**: Dedicated Cue Inspector for authoring, adjusting, and fine-tuning cues.
- **Persistent Video Player Across Modes**: The YouTube player is now shared between Playback and Edit modes. Toggling between modes no longer reloads the video, cuts audio, or resets playback time.
- **Redesigned Cue Inspector**:
  - **Timing Steppers**: Adjust start and end boundaries with micro-nudge buttons (`-0.5s`, `-0.1s`, `+0.1s`, `+0.5s`) alongside current playback time capture buttons.
  - **Dynamic Loop Preview**: Dedicated `Play Cue` and `Loop` toggle that continuously replays the exact cue segment, instantly reflecting boundary adjustments during active playback.
  - **Scene Context Window**: Displays preceding (`PREV`) and following (`NEXT`) screenplay lines directly in the inspector to anchor edits without scanning back and forth across the canvas.
  - **Anchoring Offsets & Character Span**: Explicit start/end character offsets with backspace-safe editing and live character span count.
  - **Sticky Action Bar**: Pinned bottom bar with `Update Cue` (<kbd>Ctrl+Enter</kbd>), `Cancel` (<kbd>Esc</kbd>), and `Delete`.
- **Dynamic Dirty State Tracking & Script Click Dismissal**:
  - Compares working cue drafts against baseline values to show reactive `Saved` vs `Unsaved` or `Draft` badges.
  - Clicking on clean screenplay canvas space safely dismisses the inspector back to the overview when clean, preventing accidental loss of unsaved changes.
- **Dual View Densities (Cards vs. Compact)**:
  - Easily switch between rich **Cards** view (showing character tags, formatted quotes, and offset spans) and high-density **Compact** list view (displaying single-line category chips, timestamps, and quotes).
  - Perfect for switching between visual cue auditing and scanning through dense screenplays with hundreds of cues.
  - Automatically collapses to clean icon glyphs (`[ ⊞ | ≡ ]`) on narrower panel widths.
- **Time-Clustered Cue Cards & Fluid Grid**:
  - Cues within close proximity are visually grouped into temporal clusters with sticky timecode headers (`⏱ MM:SS.s – MM:SS.s`).
  - Short action/reaction cues ($\le 1.8$s, $\le 40$ chars) render as compact mini cards, packing densely into available space while preserving full width for dialogue.
  - Two-tier visual highlighting differentiates the primary scroll-focus cue from co-active cues during playback.
- **Collapsible Search & Multi-Select Category Filters**:
  - Multi-select filtering allows toggling multiple cue categories concurrently (e.g. view `DIALOGUE` and `ACTION` together).
  - Live filter counter (`12/297`) converts into an instant 1-click reset button (`[ 12/297 ✕ ]`).
  - Search bar collapses into a single-row toolbar by default, maximizing vertical space for the cue list.
- **Collapsible YouTube Header Pill**:
  - Replaces the bulky YouTube input box in Edit Mode with a compact header status pill (`[ 🟢 {videoId} ✏️ ]`).
  - Reclaims ~50px of vertical height for video preview and cue browsing, opening an interactive overlay only when clicked.
- **Cues JSON Editor & Gemini Sync Setup**:
  - 2-column editor featuring a live JSON schema reference and quick example snippet on the left.
  - Real-time syntax and schema validation with 1-click JSON formatting that automatically unwraps `{ cues: [...] }` objects into arrays.
  - Dedicated `Sync Prompt & Schema` tab with 1-click copies for the official Gemini sync prompt and minimal JSON schema.
- **True Blank Project vs. Starter Guide Separation**:
  - **`New Project`**: Clears the workspace into an authentic blank canvas (empty script text, 0 cues) and opens directly in Edit Mode so you can immediately begin writing or pasting.
  - **`Starter Guide`**: Separated into its own dedicated menu option in `[ File ▾ ]`, loading the interactive tutorial script and cues directly in Playback Mode.
- **Studio Header & Preferences**:
  - Centered dual-mode segmented switcher (`[ ▶ Playback | ✏️ Edit ]`).
  - Hierarchical `[ File ▾ ]` dropdown menu for opening, saving, and creating projects.
  - Consolidated `[ ⚙️ Settings ▾ ]` dropdown with keyboard shortcut hints: <kbd>Shift+C</kbd> (Colors), <kbd>Shift+T</kbd> (Timing), and <kbd>Shift+R</kbd> (Reset View Layout).
  - Mode-aware layout reset: <kbd>Shift+R</kbd> restores the 40/35/25 distribution in Edit Mode while preserving the 65/35 ratio in Playback Mode.

## 🔍 Key Improvements & Technical Changes

### 1. 3-Panel Edit Layout & Resizing

Desktop Edit Mode splits the interface into three proportional columns:

```
┌────────────────────────────────────────────────────────────────────────┐
│ [◀ File]             [ ▶ Playback | ✏️ Edit ]             [⚙️ Settings] │
├─────────────────────────┬───────────────────────────────┬──────────────┤
│ LEFT PANEL (40%)        │ CENTER PANEL (35%)            │ RIGHT PANEL  │
│  ├─ Video Preview       │  ├─ Script Header Toolbar     │  (25%)       │
│  │   └─ YouTube Pill    │  │   └─ Line count & status   │  Cue         │
│  ├─ Live Timecode HUD   │  ├─ Screenplay Reading Canvas │  Inspector   │
│  └─ Sync Cues Studio    │  │   ├─ Active Highlight      │  ├─ Timing   │
│      ├─ Density [⊞ | ≡] │  │   └─ Clean-Click Dismissal │  ├─ Context  │
│      ├─ Multi-Filters   │                               │  └─ Actions  │
│      └─ Fluid Cue Grid  │                               │              │
└─────────────────────────┴───────────────────────────────┴──────────────┘
```

- **Interactive Panel Divider**: Draggable divider between the center script and right inspector supporting ratio adjustments (clamped between 18% and 45%, minimum 260px), double-click to reset (25%), and keyboard navigation.
- **Independent Layout Ratios**: Playback split ratio (`sceneflow_split_ratio`, default 65%), Edit split ratio (`sceneflow_edit_split_ratio`, default 40%), and Inspector ratio (`sceneflow_inspector_ratio`, default 25%) are persisted separately in `localStorage`.

### 2. Cross-Mode Playback Continuity

Previously, switching between Playback and Edit modes mounted distinct components, causing the YouTube iframe to unmount and remount:
- **Shared Media Viewport**: Playback and Edit modes now share a permanent video viewport.
- **Zero Interruption**: Audio continues playing, the video does not reload, and playback timestamps remain exactly where you left off.
- **Scroll Alignment**: Entering Edit Mode runs a single-tick alignment pass to center the screenplay canvas on the current active cue.

### 3. Overhauled Cue Inspector

The right panel provides dedicated controls for creating and adjusting cues:
- **Audio-Visual Timing**: Dedicated Start and End boundary cards with single-click `±0.1s` and `±0.5s` adjustment buttons.
- **Loop Preview**: Plays only the current cue's time span on repeat, with live updates allowing boundary adjustments without stopping playback.
- **Scene Context**: Displays the previous and next script lines directly in the editor for quick verification against the script.
- **Dirty State Tracking**: Highlights unsaved modifications with status badges (`Saved`, `Unsaved`, `Draft`) and safeguards against accidental loss when clicking outside.

### 4. Sync Cues Studio: Densities, Clustering, & Filtering

The left panel in Edit Mode gives you full control over how you view and organize cues:
- **Cards vs. Compact Density Switcher**: Toggle between visual cards and dense single-row list items depending on whether you are editing rich details or quickly auditing cues across a scene.
- **Temporal Clustering**: Groups cues within temporal proximity (`2.5s` gap window, max `10s` span) under sticky timecode banners, avoiding fragmented scrolling.
- **Forward Monotonic Auto-Scroll**: Edit Mode auto-scrolling prevents jittery or backward rubber-band scrolling when child cues finish inside longer parent cues.

### 5. Raw Cues JSON Modal & Gemini Sync

The raw cues modal has been redesigned into a two-column editor:
- **Live Schema Reference**: Left column displays required properties, allowed cue types (`dialogue`, `action`, `camera`, `shot`, `audio`, `vfx`, `transition`, `environment`), and optional fields.
- **Automatic Validation**: Validates JSON on keystroke, reporting syntax errors or formatted cue counts (`N cues ready`).
- **Object Unwrapping**: Automatically unwraps `{ "cues": [ ... ] }` wrappers into standard cue arrays when clicking `[ ✨ Format JSON ]`.
- **Gemini Prompts & Schema**: Ready-to-copy system prompt and minimal JSON schema for extracting cues with Gemini models via Google AI Studio or API.

### 6. Display-Rate Clock Extrapolation & Header Decoupling

- **Sub-Frame Clock Extrapolation**: Extrapolates playhead time between YouTube's 100ms clock ticks using `requestAnimationFrame`, keeping playhead motion smooth on high-refresh displays.
- **Fluid Auto-Scrolling**: Cubic ease-out auto-scrolling with passive wheel and touch listeners that immediately cancel animation if you manually scroll.
- **Header Decoupling**: Decoupled the top app header and script header controls from the 100ms playback clock tick, keeping top toolbars completely idle during playback.
- **Legacy Cleanup**: Deprecated auto-injection of `colorClass` across all cue alignment and sanitization utilities, cleaning up exported JSON while preserving backwards compatibility through legacy type mapping.

### 7. Key Bug Fixes & Mobile Geometry Restoration

- **Mobile Playback Viewport**: Resolved an issue on mobile viewports where the video container expanded to 100% height, hiding the screenplay. Restored sticky header positioning so the screenplay canvas is immediately visible and auto-scrolls beneath the video.
- **Black Screen on Cue Selection**: Fixed an issue where selecting a cue while playback was paused caused a black screen by eliminating premature pause calls during seeking.
- **Project Switching Playback Reset**: Switching projects (via the library or file menu) now cleanly resets running timers, zeroes playback state, and seeks the player back to `0:00`.

## 📦 Compatibility & Migration

- **100% Backwards Compatible**: Existing project files, exported `.json` screenplays, and cue configurations load without modification.
- **Legacy Cue Models**: Existing cues containing `colorClass` continue to render with their mapped semantic category and are cleaned automatically upon next edit or export.
- **Storage Keys**: Layout preferences are automatically migrated and preserved under `sceneflow_app_mode`, `sceneflow_edit_split_ratio`, and `sceneflow_inspector_ratio`.
