# SceneFlow v2.1.1: Precision Line-Anchored Cue Selection

> **Script-to-screen synchronization for AI filmmakers.**  
> *Release Date: August 28, 2026* • *Tag: `v2.1.1`* • *Live App: [sceneflow.taruma.my.id](https://sceneflow.taruma.my.id/)*

---

## 🚀 Overview

**SceneFlow v2.1.1** is a targeted patch release that resolves text selection positioning when creating and editing sync cues in **Edit View**. Previously, selecting words that occurred multiple times throughout a screenplay (such as repetitive camera instructions like `CAM 05`, recurring character names, or common action keywords) would default to the character offset of the *first occurrence* in the script. 

With v2.1.1, text selection is directly anchored to the specific DOM line container where the user highlights text with their mouse, guaranteeing accurate start/end index calculation anywhere in the document.

---

## 🔍 Key Improvements & Fixes

### 1. Line-Anchored DOM Offset Resolution (`src/lib/cueUtils.ts`)
- Introduced `getSelectionIndicesFromDOM(sel, scriptText)` which traverses the browser's DOM `Range` up to the nearest `[data-line-start]` line container.
- Calculates exact character offsets relative to that line's starting index in `scriptText`, preventing global `indexOf()` jumping.
- Includes local snippet matching to handle minor whitespace or formatting variations (such as brief blocks and bold anchors) while ensuring the selection remains tightly bounded to the target line.
- Implements a graceful fallback to `findTextInScript()` if DOM attributes cannot be resolved.

### 2. Line Container Metadata (`src/App.tsx`)
- Rendered screenplay lines now include `data-line-start`, `data-line-end`, and `data-line-idx` data attributes.
- Structural elements and formatted brief cards retain complete styling fidelity without visual regression.

### 3. Cue Editor Selection Handler (`src/hooks/useCueEditor.ts`)
- Updated `handleSelection()` to leverage DOM-anchored range resolution.
- Creating cues anywhere from the opening scene to the final closing action line now instantly locks onto the exact mouse-highlighted passage.

## 📦 Compatibility

- **100% Backwards Compatible**: No changes to stored JSON schemas, `Cue` interfaces, or `localStorage` configurations (`screenplay_sync_state`, `sceneflow_script_theme`, `sceneflow_script_width_preset`, `sceneflow_scroll_focus_preset`).
- **All Previous Projects Supported**: Existing projects and exported `.json` files load and synchronize seamlessly.
